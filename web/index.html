        Live tools

        Try the other five, live

        Everything below runs on input you type or files you choose, in this browser only. Nothing is uploaded. Results are computed live.

        🔐 SecretScan — live

        Paste code or config. Scans for AWS keys, GitHub tokens, Slack tokens, private-key blocks, and password / api_key assignments. Values are never shown — only type and line.

        Limit: pattern-based only. It cannot prove a file is safe, and it cannot scan a whole repo from a browser — the Python version scans files on disk.

        🔍 SemVer-Diff Web — live

        Compare two JavaScript functions on your own inputs. Web version works on JavaScript functions; the full Python AST version is in the repo (semver-diff/). Only run code you have read — never paste untrusted code here.

        🧬 TraceLock Web — live

        Choose a before-CSV and an after-CSV. Files are read in your browser only, never uploaded. Web version works on CSV files in your browser; full pipeline version is in the repo (tracelock/).


        🌱 WattShift Web — live

        Fetches the live UK Carbon Intensity forecast from api.carbonintensity.org.uk (no key needed). If the API cannot be reached, it says so plainly — no fallback numbers are shown as live data.

        ⚡ ShmPipe Web — live

        Generates rows in this browser, times a CSV string parse against a binary ArrayBuffer round-trip, and verifies the round-trip matches. Browser version measures CSV vs binary in your browser; the Python Arrow + mmap version is in the repo (shmpipe/) and measured 6.6x at 5M rows.

        How it works

        Workflow — how GuardKit works

        1

        Choose a tool

        Message or offer here, or a live panel below for code, pipelines, secrets, carbon, or data.

        2

        Paste or run

        Paste the text in your browser, choose files, or run the full python kit.py demo in a terminal. Nothing is uploaded from the web app.

        3

        Get a verdict

        A score out of 100, RED / AMBER / GREEN, with the exact flags found — not just “scam” or “safe”.

        4

        Decide, then prove

        Do not pay or forward on RED. Share the summary, or run the full suite proof and keep the report.
