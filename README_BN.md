# GuardKit — বিশ্বাস করার আগে যাচাই করুন

> **Note (English):** This is a translation only. GuardKit is a worldwide project, English primary. The main README is [README.md](README.md). Bengali support is for the trust checkers, not the project's identity.
>
> **নোট:** এটি শুধু একটি অনুবাদ। GuardKit একটি বিশ্বব্যাপী প্রজেক্ট, মূল ভাষা ইংরেজি।

**সাতটি কাজের টুল, একটাই স্যুট। প্রতিটি টুল আলাদাভাবেও চলে।**

## বিশ্বাস যাচাই (Trust)
- **SemVer-Diff** — "নিরাপদ" প্যাচে লুকিয়ে থাকা আচরণের পরিবর্তন ধরে
- **CheckFirst** — ফরওয়ার্ড করা মেসেজ পেস্ট করুন, স্ক্যাম / ভুল তথ্য যাচাই পান (বাংলা + ইংরেজি)
- **SafeOffer** — টাকা দেওয়ার আগে চাকরি / ঋণের অফার যাচাই করুন (বাংলা + ইংরেজি)
- **SecretScan** — GitHub-এ পুশ করার আগে হার্ডকোড করা সিক্রেট খুঁজুন

## পাইপলাইন (Efficiency)
- **TraceLock** — পাইপলাইনের প্রমাণ ও দুর্নীতি-সতর্কতা
- **WattShift** — ব্যাচ জব চালানোর সবচেয়ে পরিষ্কার সময় (ডেমোতে ৩৫০ গ্রাম CO2 বাঁচিয়েছে, ৬০.৩%)
- **ShmPipe** — শেয়ার্ড মেমোরি দিয়ে ডেটা পাঠানো, ৫ মিলিয়ন রো-তে CSV-র চেয়ে ৬.৬ গুণ দ্রুত

## চেষ্টা করুন
ওয়েব অ্যাপ: `web/index.html` ব্রাউজারে খুলুন — কিছু আপলোড হয় না, কিছু সংরক্ষণ হয় না।
টার্মিনাল: `python kit.py demo` — সাতটি প্রমাণ চালিয়ে `SUITE_REPORT.md` লেখে।

**সতর্কতা:** সবুজ মানে "বড় লক্ষণ পাওয়া যায়নি", প্রমাণ নয়। সবসময় BMET / দূতাবাস / নিয়োগকর্তার কাছে সরাসরি যাচাই করুন। কখনো OTP, পাসপোর্ট বা ব্যাংক তথ্য পেস্ট করবেন না।
